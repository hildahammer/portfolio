HILDA HAMMER - PORTFOLIO
=========================

Så här öppnar du sajten:
1. Packa upp/spara hela mappen "hilda-portfolio" (alla filer måste ligga ihop).
2. Dubbelklicka på index.html - den öppnas i din webbläsare.

Filer:
- index.html                          -> startsidan
- projects.html                       -> "my projects" - översikt
- project-peripheral-encounters.html  -> case study #1
- project-malmoinitiativet.html       -> case study #2
- about.html                          -> "about me"
- contact.html                        -> kontaktsida
- style.css                           -> all design/styling (en fil för hela sajten)
- script.js                           -> mobilmenyns funktion
- images/                             -> bilderna, urklippta från dina skisser

VILL DU ÄNDRA NÅGOT?
- Text: ändra direkt i html-filerna, texten ligger rakt i koden.
- Bilder: byt ut filerna i /images/ mot dina egna (behåll samma filnamn,
  eller ändra sökvägen i html:en).
- Färger/typsnitt: allt styrs från style.css (leta upp ":root" högst upp).
- Case study-sidorna har platshållartext markerad med <!-- kommentarer -->
  där du kan fylla i mer om dina projekt (bilder, process, resultat).

Att lägga upp sajten live (gratis):
- Netlify (drop-hela-mappen: app.netlify.com/drop)
- GitHub Pages
